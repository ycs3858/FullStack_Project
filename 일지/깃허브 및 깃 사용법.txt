깃 브런치 확인
git branch

이동
git checkout (브런치명)

생성 및 이동

git checkout -b (브런치명)



저장 방법

git add .
git commit -m "커밋메시지"
push 



git에 커밋하고 싶지 않은 파일은
.gitignore안에 작성


---------------------------------------------------------
git rm -r --cached .
git add .
git commit -m "apply gitignore"
git push


git rm -r --cached .
👉 Git이 추적하던 파일을 전부 추적 해제
(내 컴퓨터 파일은 그대로 👍)
git add .
👉 .gitignore 기준으로 다시 추가
(불필요한 파일은 자동 제외됨)
commit & push
👉 GitHub에도 반영됨

-------------------------------------------------------------

git status // 수정 및 추가 사항 확인


git add . // 수정된 파일 전부 올릴 준비

git add src/App.jsx //특정 파일만 올리기
(내 위치 기준 경로)
ex) frontend에 있는 scr 밑 App,jsx만 올리고 싶을 때
project에 있는 경우 : git add frontend/src/App.jsx
frontend에 있는 경우 : git add src/App,jsx


git commit -m "변경내용이나 커밋하면서 작성할 내용"
// 변경 사항을 커밋(저장) 및 설명 메시지


git push // 깃허브에 업로드


git remote set-url origin https://github.com/새계정/새레포지토리.git
// 레포지토리 변경 명령어. github에 미리 새레포지토리를 만들어놔야함
