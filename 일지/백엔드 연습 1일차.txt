1. node.js 설치

vscode 터미널을 powershell -> cmd 변경
npm init -y 실행 // 패키지 생성 / 프로젝트 관리할 설정 파일 생성


2. npm install express (기능 추가)
express 설치
(관리 및 서버를 위한 라이브러리 추가)


3. node index.js (서버 실행)
index.js 파일을 만들고 서버 코드 작성
--------------------------------------------------------
const express = require('express');
const app = express();

// JSON 요청 처리
app.use(express.json());

// 기본 테스트 API
app.get('/', (req, res) => {
  res.send('서버 실행 성공!');
});

// 서버 실행
app.listen(3000, () => {
  console.log('서버가 3000번 포트에서 실행 중');
});
----------------------------------------------------------
node index.js로 index.js 서버 실행

localhost:3000으로 페이지 접속 (index.js 파일 안에 포트 3000 정의)


3-2. index.js 수정 후 get/post 테스트

// 회원가입
