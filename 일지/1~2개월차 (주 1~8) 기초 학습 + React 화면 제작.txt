1~2개월차 (주 1~8): 기초 학습 + React 화면 제작
 주 1: JS 변수, 함수, 배열, 객체, 반복문, 조건문, async/await 복습
 주 2: JS ES6+ 문법 복습 (화살표 함수, 클래스, 디스트럭처링)
 주 3: React 컴포넌트, props, state, useEffect, JSX 학습
 주 4: React 이벤트 처리 학습 (버튼, 폼, 상태 변경, 리스트 렌더링)
 주 5: CRUD 게시판 페이지 (리스트 + 글 작성/수정 화면) 제작
 주 6: 글 상세 페이지 + 삭제 기능 구현
 주 7: 더미 데이터(JSON) 연결 후 CRUD 동작 확인
 주 8: UI 다듬기 (CSS, 페이지네이션 기본 적용)


3~4개월차 (주 9~16): Node.js + DB 연동 + API 연결
 주 9: Node.js + Express 서버 구축, 라우팅
 주 10: REST API 구현 (GET/POST/PUT/DELETE)
 주 11: DB 연결 (MySQL/MongoDB), Users/Posts 테이블/컬렉션 생성
 주 12: CRUD API → DB 연동
 주 13: React ↔ Node.js API 연결, 게시판 CRUD 동작 확인
 주 14: 회원가입 기능 구현 (POST /register)
 주 15: 로그인 기능 구현 (POST /login), JWT 발급, localStorage 저장
 주 16: 인증 처리 미들웨어 적용, 로그인한 사용자만 글 작성/수정/삭제 가능

5~6개월차 (주 17~24): 프로젝트 확장 + UX/상태관리
 주 17: 상태 관리 적용 (useContext 또는 Redux)
 주 18: 글 작성/수정 UX 개선, 입력 검증, 에러 메시지 표시
 주 19: 게시글 검색 기능 구현 (제목/내용)
 주 20: 댓글/좋아요 기능 구현 (선택적)
 주 21: 프로젝트 2개째 기능 구상 (예약 시스템/쇼핑몰)
 주 22: 프로젝트 2 완성 (CRUD + 로그인 연동, DB 연결)
 주 23: 코드 리팩토링, 불필요 코드 제거, 함수/컴포넌트 정리
 주 24: 프로젝트 구조 정리 (폴더 구조, API 모듈화, 환경변수 관리)

7개월차 (주 25~28): 배포 + 포트폴리오 정리
 주 25: 프론트 배포 (Netlify 또는 Vercel)
