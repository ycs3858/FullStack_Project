8개월 현실 로드맵: Node.js + React 풀스택 프로젝트
1~2개월차 – 기초 학습 및 간단 UI 제작

목표: JavaScript/React 기본 숙지 + CRUD 게시판 화면 구성

주별 목표
주 1~2: JavaScript ES6+ 문법 복습 (변수, 함수, 클래스, 배열, 객체, async/await)
주 3~4: React 기본 문법 (컴포넌트, props, state, useEffect)
주 5~6: 간단 CRUD 화면 구현 (게시판 리스트 + 글 작성/수정/삭제 화면)
주 7~8: React 화면과 더미 데이터(JSON) 연결
포인트: 화면이 동작하고, UI 흐름 이해하는 수준이면 충분
3~4개월차 – Node.js + DB 연동

목표: 백엔드 REST API 구현 + DB 연동 + 프론트와 연결

주별 목표
주 9~10: Node.js + Express 서버 기본 구축, REST API 작성 (GET/POST/PUT/DELETE)
주 11: MySQL 또는 MongoDB 연동, 간단한 CRUD 연동
주 12: React와 API 연결 (fetch/axios), 게시판 CRUD 완성
주 13~16: JWT 로그인/회원가입 구현, 인증 처리 테스트
포인트:
프론트 → 백엔드 → DB → 프론트 순서로 흐름 이해
최소 하나의 작동 가능한 CRUD + 로그인 기능 확보
5~6개월차 – 프로젝트 확장 및 기능 완성

목표: 실무 느낌 프로젝트 완성 + 상태관리/UX 개선

주별 목표
주 17~18: 상태 관리 구현 (React useContext 또는 Redux 간단 적용)
주 19~20: 예외 처리, 입력 검증, UI/UX 개선
주 21~22: 프로젝트 2개째 구상 또는 기능 확장 (예: 예약 시스템, 간단 쇼핑몰)
주 23~24: API 구조 정리, 코드 리팩토링
포인트:
프로젝트 2개 완성 목표
면접용으로 기능 시연 가능
7개월차 – 배포 및 포트폴리오 정리

목표: 실제 서비스처럼 배포 + GitHub 정리

주별 목표
주 25~26: Heroku, Netlify, Render, 또는 AWS EC2 배포
주 27: GitHub 코드 정리, README 작성, 프로젝트 설명 준비
주 28: 포트폴리오 문서화 (기술 스택, 기능 설명, 프로젝트 시연 링크)
포인트:
“동작하는 웹 서비스 + 깔끔한 코드 + GitHub 공개” → 면접 경쟁력 상승
8개월차 – 이력서 & 면접 준비

목표: 취업 지원 + 면접 대비

주별 목표
주 29: 이력서 작성 + 지원할 기업 리스트 정리
주 30: 프로젝트 시연 연습, 질문 예상 답변 준비
주 31: 기본 백엔드/프론트 개념 Q&A 준비 (HTTP, REST, JSON, DB, 인증)
주 32: 모의 면접 / 최종 체크
포인트:
프로젝트 + 네트워크 경험 연계 → 면접 차별화
프론트/백엔드/풀스택 모두 지원 가능
